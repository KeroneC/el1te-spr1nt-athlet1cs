# Deployment Documentation

Phase 6B operates a manually approved Azure demo in Central US. Read [CI/CD overview](architecture/cicd-overview.md), [Azure demo continuous delivery](architecture/future-azure-deployment.md), [Azure setup and release](guides/future-azure-setup.md), [observability and support references](guides/observability-support.md), [store and Square foundation](guides/store-square-foundation.md), and [public storefront and configurator](guides/store-public-configurator.md).

Commerce deployments must keep `Store__Enabled=false` until the documented final cutover. The demo deployment sets `Store__PublicPreviewEnabled=true`, which exposes the catalog, configurator, and non-personal cart to internal reviewers while Square checkout, webhooks, order creation, reservations, and commerce workers remain disabled. Production should keep the preview flag false unless an equally explicit review decision is recorded. Square access tokens and webhook signature keys belong in Azure Key Vault and enter App Service only through Key Vault references. The private one-time catalog import can run while full commerce is disabled, but only after the Square access-token secret URI and selected location ID are supplied through the existing deployment inputs.
