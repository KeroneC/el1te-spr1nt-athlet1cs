## Coaches: support staff section

To add a group photo below the coach profiles, upload the approved landscape image in **Admin → Media** and copy its public URL. In **Admin → Content**, create a block with the exact key `coaches.support-staff`. Set the title (for example, “Support Staff”), put the public introduction in **Body**, and paste the Media Library URL into **Image URL**. Use **Summary** for concise alt text describing the group photo; it is not displayed as page copy. The CTA fields are unused for this section.

Leave the block in Draft until the photo and copy are approved. Publish it to show the section, or unpublish it to hide the section without deleting anything. A missing block or photo does not change the coach profiles. Use the regular Media Library, not the private Historical Photos archive.
